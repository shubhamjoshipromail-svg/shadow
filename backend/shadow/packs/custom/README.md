# Custom packs (`packs/custom/`)

Task definitions generated by cold start ("watch me do this") land here.

- Written by `shadow.onboard.save_task_definition(task)` as `<slug>.json` with a
  `version` (bumped on every re-save).
- Read with `shadow.onboard.load_custom_taskdef(slug)` /
  `shadow.onboard.list_custom()`.
- Loaded by the engine exactly like any other workflow:
  `GenericPack(load_custom_taskdef(slug))` — `Pack` protocol only, no engine change.

The files are produced artifacts; edit a `TaskDefinition` through the API
(`POST /api/onboard`) rather than by hand, so the demo cases and versions stay
consistent.

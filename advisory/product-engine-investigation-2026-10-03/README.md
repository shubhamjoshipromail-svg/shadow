# Shadow: product and engine investigation

Prepared 2026-10-03 for the user and Opus. Advisory only: no application changes, server restarts, active-session mutations, or agent assignments. Source snapshot: `be00baadcd0db27070d2f023d3411498f7f49b19`. Opus is actively working; recheck source hashes in `verification.json` before acting on a finding.

**Verdict:** Shadow has a real executable knowledge engine and a substantial invoice demo. It does not yet provide a general apprentice that discovers arbitrary tasks. Live end-to-end learning reliability remains unestablished by this audit. The synthetic evaluation must not be presented as measured live performance.

**Product:** two frontend applications (ERP and Shadow console), several console views, and an embedded voice/text companion. There is no packaged browser extension or complete company/assignment/multi-expert product in this checkout. The companion can become a browser extension without requiring a native application.

**Visualization:** a clickable Work Map, hypothesis bars, threshold curves, and a session feed already exist in code. The map is a structured step/rule/evidence view, not a general graph of dependencies and conflicts. It exposes application knowledge, not the language model's internal reasoning.

## X · EXTENSION — new `extension/**` only (Chrome MV3, load-unpacked)
Goal: Mira appears on any site the user turns her on for, not only our ERP.
- `manifest.json` (MV3): name `NAME`, action popup, `storage`, `scripting`, `activeTab`, optional host permissions
  `https://*/*`, `http://localhost/*`. No remote code in the extension itself.
- Popup (design system, 320px): server URL (default `https://core-production-c5ac.up.railway.app`), toggle
  "Turn on Mira for <this site>" which requests that origin's permission and remembers it; list of enabled sites.
- On enabled origins, a content script injects into the page (MAIN world via `chrome.scripting.executeScript` with
  `world: "MAIN"`) a tiny bootstrap that sets `window.SHADOW_API` (and `window.SHADOW_NAME`) and then loads the
  companion and observer **bundled in the extension**: copies of `backend/shadow/static/capture.js` and
  `observe.js` placed in `extension/vendor/` by `extension/sync.sh` (which you write; it copies from backend). Wire
  `observe.js` events to the companion's socket only when the page did not already load `capture.js` itself (our
  ERP does) — never double-inject (`window.__shadowCapture`).
- Re-inject on SPA navigations; survive reloads.
- `extension/README.md`: load-unpacked steps (3 lines), what it can and can't do on arbitrary sites.
Acceptance: `node` syntax checks; load it in headless Chrome with `--load-extension` against a local static test page
(`extension/test/page.html`, a plain form) served on :8098 with server URL :8001, and screenshot Mira on that page.
